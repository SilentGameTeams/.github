# Silent Game

**SilentStudio 산하 개발 팀**

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | 한국어 | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Русский](README.ru.md)

Silent Game는 SilentStudio 산하의 개발 팀으로, 게임 엔진, 실시간 시뮬레이션, 크로스플랫폼 게임, 플레이어 도구를 다룹니다. 우리 프로젝트가 반드시 오픈소스인 것은 아니며, 공개 프로젝트는 그렇게 표시합니다.

팀은 여러 프로젝트와 영역에 걸쳐 활동하며, 여기서 개별 프로젝트를 나열하지 않습니다. 우리는 엔지니어링 품질, 유지보수성, 다국어·다플랫폼 실천, 커뮤니티 협업을 중시합니다.

## 참여

- 공개 프로젝트에서는 issue와 pull request를 환영합니다. 비공개 프로젝트는 외부 기여를 받지 않습니다.
- 각 저장소의 CONTRIBUTING을 따라 주세요
- 다른 사람의 작업을 덮어쓰지 말고 main에 force-push하지 마세요

## 유지보수 및 보안

- Silent Game는 보안 보고를 중시하고 투명하게 대응합니다. 이 정책은 Silent Game가 유지보수하는 프로젝트에 적용됩니다.
- 최신 안정판은 전체 보안 업데이트를 제공하고, 이전 안정판은 중요 수정만, 그 이전 버전은 요청 시 지원합니다.
- 취약점은 SilentStudio@feedback.email.cn으로 보고하고, 수정 전에는 세부 내용을 공개하지 마세요.
- 접수 확인은 24시간 이내, 검증은 48시간 이내, 중요 수정 계획은 7일 이내, 중·저위험은 14일 이내입니다.
- 선의의 보고자는 추적하지 않습니다. 데이터 악용이나 시스템 방해를 하지 마세요.
- 소유한 시스템 또는 서면으로 허가된 테스트에만 사용하세요. 은닉, 회피, 무단 원격 제어는 제공하지 않습니다.
- 최종 업데이트: 2026-11-05.
