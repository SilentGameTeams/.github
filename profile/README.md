Silent Game 是 SilentStudio 旗下的开发团队，关注游戏引擎、实时模拟、跨平台游戏与玩家工具。我们的项目不一定开源；公开项目会明确标注。

团队的工作覆盖多个项目与方向，不在此逐个列出。我们更关注工程质量、可维护性、多语言与多平台实践，以及与社区协作的方式。

## 参与

- 遵守各仓库的 CONTRIBUTING
- 不覆盖他人的工作，不 force-push main

## 维护与安全政策

### 我们的承诺

Silent Game 重视用户数据安全与项目稳定性。我们会及时响应安全漏洞，透明处理，并与社区共同维护安全生态。本政策适用于 Silent Game 维护的项目。

### 支持的版本

| 版本类别 | 安全更新支持 | 支持周期 |
| --- | --- | --- |
| 最新稳定版 | 全面支持 | 直至下一个大版本发布 |
| 上一个稳定版 | 仅修复 Critical 漏洞 | 发布后 6 个月 |
| 旧版本 | 按需修复 | 另行通知 |

Critical 漏洞包括远程代码执行、数据泄露、身份认证绕过等可能导致严重后果的问题。

### 报告漏洞

请通过 SilentStudio@feedback.email.cn 报告漏洞，请勿在公开渠道（如 Issues、讨论区）发布漏洞细节。

报告请包含：漏洞类型与影响范围、复现步骤（含环境）、证明（PoC 或截图）、联系方式。

### 处理流程

| 阶段 | 时限 |
| --- | --- |
| 确认接收 | 24 小时内 |
| 漏洞验证 | 48 小时内 |
| Critical 修复 | 7 天内提供修复方案 |
| 中低危修复 | 14 天内提供修复计划 |
| 公开披露 | 修复发布后同步公开 |

### 负责任披露原则

善意报告者不会因测试行为被追责，但需遵守：

- 不滥用漏洞获取数据或破坏系统
- 漏洞修复前保持信息机密

### 使用边界

- 仅用于自有系统或获得书面授权的测试
- 不提供隐蔽、规避监控或未经授权的远程控制
