Silent Game es el equipo de juegos de SilentStudio.

Hacemos para Windows, macOS, iOS y Android, y escribimos también el motor, las herramientas y los formatos de debajo. Casi todo el trabajo pasa donde el jugador no mira.

Los proyectos no siempre son de código abierto. Los que lo son, lo dicen.

## Contribuir

- Los proyectos públicos aceptan issues y pull requests. Los privados siguen privados.
- Sigue el CONTRIBUTING de cada repositorio.
- No sobrescribas el trabajo de otros ni hagas force-push a main.
